# CV Project Summary

## CV-Ready Summary

Built an evidence-grounded financial advisory platform with RAG, multi-agent reasoning, compliance validation, evaluation governance, human review, quality analytics, golden benchmarking, and error recovery.

## CV-Ready Bullets

- Designed a task-scoped RAG pipeline with QueryPlan, ContextRequirements, EvidenceBundle, evidence sufficiency, source validation, and controlled failure behavior.
- Built a generic analytical agent runtime with MarketContext, Strategy, Risk, and Consistency agents while preserving EvidenceBundle authority.
- Implemented compliance and answer-completeness gates to keep outputs advisory, source-grounded, and non-executable.
- Added post-answer governance with JournalReview, BacktestEvaluation, PaperTradingEvaluation, EvaluationRegistry, and deterministic ReplayHarness.
- Built a review dashboard with registry table, detail panel, chain view, replay display, persistence, human annotations, analytics, and system health diagnostics.
- Implemented local JSONL/JSON persistence, dataset versioning, safe exports, bounded reason-code annotations, and quality metrics.
- Created a golden benchmark suite and system hardening layer for deterministic regression checks, corrupt JSONL detection, quarantine, and diagnostic export.

## Wording to Avoid

- Built an automatic trading system.
- Built a profit-guaranteeing trading system.
- Generates executable trade instructions.
- Promises trading performance.

## Safe Positioning

This is an advisory and evaluation governance platform. It does not perform live trading, MT5 order placement, broker execution, account-data usage, position sizing, or account-risk recommendations.
